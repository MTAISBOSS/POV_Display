POV Display Project

Create mesmerizing persistence-of-vision displays with LEDs and a hall effect sensor

🌟 Project Overview

This project creates a Persistence of Vision (POV) display using LEDs mounted on a rotating platform. When spun, it displays text, animations, and even a clock through precise timing of LED activation.

🔄 Rotation Detection

Uses a hall effect sensor to detect rotation and synchronize the display

🕒 Time Display

Shows current time (hours, minutes, seconds) in a digital format

💖 Custom Animations

Includes special animations like hearts and hypnotic patterns

🎵 Lyric Sync

Can display song lyrics synchronized with playback timing

🛠️ Hardware Requirements

  • Microcontroller (supports MicroPython)
  • 8 LEDs (connected to pins 7-14)
  • 2 additional "beauty" LEDs (pins 6 and 15)
  • Hall effect sensor (pin 16)
  • Magnet (for triggering the hall sensor)
  • Rotating platform (fan, motor, or manually spun)

🚀 Setup Guide

1

Hardware Assembly

Connect all components according to the pin configuration:

led_pins = [Pin(i, Pin.OUT) for i in range(7, 15)]
beauty_leds = [Pin(6, Pin.OUT), Pin(15, Pin.OUT)]
hall_sensor = Pin(16, Pin.IN, Pin.PULL_UP)

Mount the LEDs vertically on your rotating platform and position the hall sensor so it's triggered once per rotation.

2

Upload the Code

Copy the provided Python code to your microcontroller. The main components are:

  • LED pattern definitions for numbers and letters
  • Time-keeping functions
  • Display functions for text, time, and animations
  • Main loop with hall sensor detection
3

Customize Your Display

Modify these variables to change what's displayed:

text_to_show = "ATM"  # Change to your desired text
COLUMN_DELAY = 0.001  # Adjust for rotation speed
DIGIT_SPACE = 2       # Space between characters

You can also add custom patterns to the characters dictionary or create new animations.

4

Power Up and Spin

Power your microcontroller and spin the display. The hall sensor will detect each rotation and trigger the display.

The code includes different display modes that activate based on time:

  • 0-15s: LEDs turn on one by one
  • 15-30s: Hypnotic swirling pattern
  • 30-45s: Ping-pong LED effect

🎨 Customization Options

Pro Tip: The display timing is critical. Adjust COLUMN_DELAY based on your rotation speed for optimal results.

Adding New Characters

Extend the characters dictionary with your own 5-column patterns: 

characters = {
    # ... existing characters ...
    "!": [0b00000000, 0b00000000, 0b11111000, 0b00000000, 0b00000000],
    "?": [0b01000000, 0b10000000, 0b10001000, 0b01010000, 0b00100000],
    # Add more characters here
}

Creating Animations

Define new animation patterns as arrays of byte patterns:

def my_animation():
    pattern = [
        0b00000001,
        0b00000011,
        0b00000111,
        # ... more frames ...
    ]
    while True:
        for col in pattern:
            clear_leds()
            send_to_pins(col)
            sleep(COLUMN_DELAY)

🔧 Troubleshooting

  • Display appears blurry: Adjust COLUMN_DELAY to match your rotation speed
  • Hall sensor not triggering: Check magnet alignment and sensor connections
  • LEDs not lighting: Verify your pin connections and LED orientations
